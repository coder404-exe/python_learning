# Python Data Types Notes

## 1. Integer (`int`)
- Stores whole numbers
- No decimal values

### Example
```python
age = 20
marks = 95
```

---

## 2. Float (`float`)
- Stores decimal numbers
- Used for precision values

### Example
```python
price = 99.99
height = 5.8
```

---

## 3. String (`str`)
- Stores text or characters
- Written inside quotes

### Example
```python
name = "Vaibhav"
city = 'Latur'
```

---

## 4. Boolean (`bool`)
- Stores only two values:
  - `True`
  - `False`

### Example
```python
is_logged_in = True
is_passed = False
```

---

## 5. List (`list`)
- Ordered collection
- Mutable (can change)
- Uses square brackets `[]`

### Example
```python
numbers = [1, 2, 3, 4]
names = ["Ram", "Sham", "Om"]
```

---

## 6. Tuple (`tuple`)
- Ordered collection
- Immutable (cannot change)
- Uses parentheses `()`

### Example
```python
colors = ("red", "blue", "green")
```

---

## 7. Set (`set`)
- Stores unique values only
- Unordered collection
- Uses curly brackets `{}`

### Example
```python
fruits = {"apple", "banana", "mango"}
```

---

## 8. Dictionary (`dict`)
- Stores data in key-value pairs
- Uses curly brackets `{}`

### Example
```python
student = {
    "name": "Vaibhav",
    "age": 20,
    "branch": "CSE"
}
```

---

## 9. None Type (`NoneType`)
- Represents no value or empty value

### Example
```python
data = None
```
